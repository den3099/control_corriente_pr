## Introducción

Implementación de un sistema de control de corriente para un inversor monofásico mediante un regulador proporcional-resonante (PR) discreto, ejecutado sobre un procesador MicroBlaze V en FPGA. La solución integra hardware digital y software embebido para adquirir, procesar y regular la corriente de salida.
